How to Play

  • Predict the exact scoreline for any World Cup group-stage match.
  • You can skip matches — skipped matches score 0 points.
  • Submit before the match kicks off. Matches are locked at kickoff.
  • Check the leaderboard live as results come in.

Scoring System

5 pts 🎯 Exact score
3 pts ✅ Correct result
+1 pt 📐 Correct goal difference
0 pts ❌ Wrong outcome
Examples:
Predicted 2–1, Actual 2–1 → 5 pts (exact!)
Predicted 2–1, Actual 1–0 → 3 pts (correct result, diff = 1 in both)
Predicted 2–0, Actual 3–1 → 3+1 = 4 pts (result + goal diff bonus)
Predicted 1–2, Actual 2–0 → 0 pts (wrong outcome)
